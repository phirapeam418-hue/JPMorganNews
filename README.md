# Tech News Bot (ฟรี): Gemini + Telegram

ดึงข่าวจาก RSS → อ่านเนื้อข่าวเต็ม → Gemini ให้คะแนน 4 เกณฑ์ + รวมข่าวซ้ำ + สรุปอังกฤษ → ส่งเข้า Telegram

## บอททำอะไรได้บ้าง

| ฟีเจอร์ | รายละเอียด |
|---|---|
| แจ้งข่าวด่วน | คะแนน 8-10 หรือข่าวที่ตรง watchlist ส่งทันที (ไม่เกิน 5 ข่าวต่อรอบ) |
| สรุปรายวัน | คะแนน 5-7 ส่งตอน 08:05 น. (ไม่เกิน 8 ข่าว) |
| สรุปรายสัปดาห์ | วันอาทิตย์ 09:10 น. ส่ง 5 ข่าวเด่นของสัปดาห์ + สถิติคำศัพท์ |
| ควิซคำศัพท์ | ทุกวัน 20:15 น. 5 ข้อ หรือพิมพ์ `/quiz` ได้ทุกเมื่อ (ดูหัวข้อ "คำศัพท์และควิซ") |
| รวมข่าวซ้ำ | ข่าวเรื่องเดียวกันจากหลายสำนักรวมเป็นข้อความเดียว พร้อม "Also reported by" |
| ช่วงห้ามรบกวน | 23:00-07:00 ไม่มีแจ้งเตือน ข่าวด่วนช่วงนั้นเก็บไว้ส่งตอนเช้า |
| ปุ่มใต้ข่าว | 👍/👎 สอนบอทว่าชอบข่าวแบบไหน, 📖 More ขอคำอธิบายยาวขึ้น |
| ถามเรื่องข่าว | กด "ตอบกลับ" ที่ข่าว แล้วพิมพ์คำถามภาษาอังกฤษ บอทจะตอบจากเนื้อข่าว |
| แจ้งเตือนเมื่อบอทมีปัญหา | ถ้า feed, Gemini, Telegram หรือ Notion error ติดกัน 3 รอบ หรือการรันล้มเหลว จะส่งข้อความบอก |
| บันทึกลง Notion | (ไม่บังคับ) ทุกข่าวที่ส่งถูกเก็บลงฐานข้อมูล Notion |

**สำคัญ:** บอทไม่ได้เปิดรอตลอดเวลา จะเช็กปุ่มและข้อความของคุณทุกครั้งที่รัน (ประมาณชั่วโมงละครั้ง) ดังนั้นคำตอบอาจมาช้าสุดราว 1 ชั่วโมง

**รันครั้งแรก:** บอทจะจำข่าวที่มีอยู่แล้วโดยไม่ส่ง และส่งแค่ข้อความ "Bot started" ข่าวจริงเริ่มมาตั้งแต่รอบถัดไป

## คำศัพท์และควิซ
- **ระดับคำศัพท์**: เริ่มที่ CEFR **B2** บอกให้ Gemini เลือกคำระดับนี้ขึ้นไป ห้ามคำพื้นฐาน (A1-B1) ห้ามตัวย่อ/ชื่อสินค้า และห้ามคำที่เคยได้ไปแล้ว ศัพท์เทคนิคไม่เกิน 1 คำต่อข่าว
- **ระดับปรับเอง**: ดูจากคำตอบ 20 ข้อล่าสุด ถ้าถูก 85% ขึ้นไป ระดับขึ้น (B2 → C1 → C2) ถ้าถูกน้อยกว่า 50% ระดับลง หรือตั้งเองด้วย `/level C1`
- **โจทย์ 2 แบบสลับกัน**: (1) คำนี้แปลว่าอะไร มีประโยคตัวอย่างประกอบ ตัวเลือกเป็นภาษาไทย (2) เติมคำในช่องว่าง ตัวเลือกเป็นภาษาอังกฤษ
- **ลำดับคำที่ถาม**: คำที่เคยตอบผิดก่อน → คำที่ยังไม่เคยถาม → คำอื่น
- **จำได้แล้ว (mastered)**: ตอบถูกติดกัน 3 ครั้ง คำนั้นจะไม่ถูกถามอีก
- ดูความคืบหน้าได้ด้วย `/status`

## คะแนนคิดจากอะไร
Gemini ให้คะแนน 1-10 แยก 4 ข้อ แล้วบอทเฉลี่ยเป็นคะแนนรวม (ปรับน้ำหนักที่ `CRITERIA`)

| ตัวย่อ | เกณฑ์ | ความหมาย |
|---|---|---|
| I | impact | กระทบงานคุณโดยตรงแค่ไหน (ดูจาก `MY_FIELD` และปุ่ม 👍/👎) |
| U | urgency | เกิดตอนนี้ / ต้องรีบลงมือไหม |
| S | scale | กระทบคนหรือบริษัทมากแค่ไหน |
| C | credibility | แหล่งข่าวน่าเชื่อถือแค่ไหน |

ตัวอย่างข้อความ:
```
🔴 [9/10] 👀 watchlist Major outage hits cloud region
(I9 U10 S9 C8) Ongoing outage in a region used by many companies.

A large outage stopped many websites for two hours...
• redundancy (B2) = ระบบสำรอง
• mitigate (C1) = บรรเทา
• cascading (C1) = ลุกลามต่อเนื่อง
https://...
Also reported by:
https://...
[ 👍 ] [ 👎 ] [ 📖 More ]
```

## ตั้งค่า

### 1) Telegram bot
1. ค้นหา **@BotFather** ใน Telegram → `/newbot` → ได้ token = `TELEGRAM_BOT_TOKEN`
2. เปิดแชทกับบอท กด Start แล้วพิมพ์อะไรก็ได้ 1 ข้อความ
3. เปิด `https://api.telegram.org/bot<TOKEN>/getUpdates` ในเบราว์เซอร์ หา `"chat":{"id": ...}` = `TELEGRAM_CHAT_ID`

### 2) Gemini API key (ฟรี)
https://aistudio.google.com/apikey → Create API key = `GEMINI_API_KEY`
**อย่ากด Set up billing** จะได้ไม่มีทางโดนเก็บเงิน

### 3) ทดลองรันในเครื่อง
```bash
pip install -r requirements.txt
# Windows ใช้ set แทน export
export GEMINI_API_KEY=...
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_CHAT_ID=...
python bot.py alert     # รอบแรก: ได้ข้อความ "Bot started"
python bot.py alert     # รอบสอง: เริ่มส่งข่าว (ถ้ามีข่าวใหม่)
python bot.py digest
python bot.py quiz      # ควิซจะเริ่มได้เมื่อมีคำศัพท์สะสมอย่างน้อย 4 คำ
python bot.py weekly
```
ถ้าอยากทดสอบให้เห็นข่าวเร็วๆ ลบไฟล์ `state.json` แล้วลด `ALERT_MIN` เหลือ 3 ชั่วคราว
(หมายเหตุ: บอทเริ่มจับข้อความจาก getUpdates ทันที ข้อความที่คุณพิมพ์ตอนหา chat ID จะได้รับคำตอบเป็นคำแนะนำการใช้งาน ไม่ต้องตกใจ)

### 4) GitHub Actions
1. สร้าง repo ใหม่ อัปโหลดไฟล์ทั้งหมด รวมโฟลเดอร์ `.github` (ไม่ต้องอัปโหลด `state.json` จากเครื่อง)
2. Settings → Secrets and variables → Actions → เพิ่ม secret: `GEMINI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
3. แท็บ Actions → เลือก workflow → Run workflow (mode: alert) เพื่อทดสอบ

**แนะนำให้ทำ repo เป็น public:** รัน Actions ได้ฟรีไม่จำกัดนาที key ยังปลอดภัยเพราะอยู่ใน Secrets
ถ้าใช้ private repo บอทที่รันทุกชั่วโมงอาจเกินโควตาฟรีราว 2,000 นาที/เดือน ให้แก้ cron แรกเป็น `"0 */2 * * *"` (ทุก 2 ชม.)

### 5) Notion (ไม่บังคับ)
1. https://www.notion.so/my-integrations → New integration → คัดลอก token = `NOTION_TOKEN`
2. สร้าง database ใน Notion โดยตั้งชื่อคอลัมน์ให้ตรงนี้ทุกตัว:
   `Name` (Title), `URL` (URL), `Score` (Number), `Summary` (Text), `Vocab` (Text), `Date` (Date)
3. ที่หน้า database กด `...` → Connections → เพิ่ม integration ที่สร้าง
4. คัดลอก database ID จากลิงก์ (ตัวอักษร 32 ตัวก่อน `?v=`) = `NOTION_DATABASE_ID`
5. เพิ่มทั้งสองเป็น GitHub secret ถ้าไม่ใส่ บอทจะข้ามส่วนนี้ไปเอง

## ค่าที่ปรับได้ (ด้านบนของ bot.py)
| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `MY_FIELD` | สาย data center | อธิบายงานคุณ ยิ่งละเอียดคะแนน impact ยิ่งแม่น |
| `WATCHLIST` | outage, zero-day, ... | คำที่เจอแล้วส่งทันทีไม่สนคะแนน |
| `CRITERIA` | น้ำหนักเท่ากัน | เช่น `"urgency": 2.0` ให้ข่าวด่วนสำคัญขึ้น |
| `ALERT_MIN` / `DIGEST_MIN` | 8 / 5 | เกณฑ์คะแนน |
| `MAX_ALERTS_PER_RUN` | 5 | แจ้งเตือนสูงสุดต่อรอบ ที่เกินไปเข้าสรุปรายวัน |
| `QUIET_HOURS` | (23, 7) | ช่วงห้ามรบกวน |
| `VOCAB_PER_STORY` | 3 | คำศัพท์ต่อข่าว |
| `VOCAB_LEVEL` | B2 | ระดับคำศัพท์เริ่มต้น (B1, B2, C1, C2) |
| `AUTO_LEVEL` | True | ปรับระดับตามผลควิซ |
| `MASTERED_AFTER` | 3 | ตอบถูกติดกันกี่ครั้งถึงนับว่าจำได้ |
| `QUIZ_QUESTIONS` | 5 | จำนวนข้อควิซต่อวัน |
| `QUIZ_MIN_WORDS` | 4 | ต้องมีคำสะสมอย่างน้อยเท่านี้ถึงจะเริ่มควิซได้ |
| `MAX_NEW_PER_RUN` / `BATCH_SIZE` | 24 / 8 | คุมโควตา Gemini (ใช้ราว 3 ครั้งต่อรอบ) |

## คำสั่งใน Telegram
- ตอบกลับข่าว + พิมพ์คำถาม → ถามเรื่องข่าวนั้น
- `/quiz` → ควิซคำศัพท์ทันที
- `/level C1` → เปลี่ยนระดับคำศัพท์
- `/status` → จำนวนข่าวที่รอส่ง, คำศัพท์ที่สะสม, ปัญหาที่เจอ
- `/help` → วิธีใช้

## ถ้ามีปัญหา
- **"model not found"**: ชื่อโมเดลฟรีเปลี่ยนบ่อย ดูชื่อล่าสุดที่ aistudio.google.com แล้วแก้ `MODEL`
- **error 429**: ใช้โควตา Gemini เกิน ลด `MAX_NEW_PER_RUN` หรือลดความถี่ cron
- **บางเว็บอ่านเนื้อข่าวเต็มไม่ได้** (ติด paywall หรือบล็อกบอท): บอทจะใช้สรุปจาก RSS แทนอัตโนมัติ
